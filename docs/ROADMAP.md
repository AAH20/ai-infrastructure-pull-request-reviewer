# Roadmap

## v0.1 — review kernel

Deterministic normalized evidence ingestion, dependency impact, business metrics, decisions, reports, Action and fixtures.

## v0.2 — native evidence adapters

Terraform/OpenTofu plan JSON, Checkov JSON, Infracost JSON, ChangeBench receipts and Azure resource graph normalization.

## v0.3 — pull-request product

GitHub Checks API, idempotent webhook processing, installation authorization, Azure Container Apps, PostgreSQL audit history and OpenTelemetry.

## v0.4 — platform breadth

Bicep/ARM what-if, Kubernetes dry run, Helm, Ansible check mode, network digital-twin evidence and Backstage integration.

## v1.0 — enterprise operation

Signed provenance, evidence custody, tenant isolation, SLOs, documented threat model, disaster recovery, policy packs and reproducible public benchmarks.
